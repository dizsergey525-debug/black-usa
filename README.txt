BLACK USA 3D v0.1
Распакуй ZIP. Главный файл — index.html.
Открой его в редакторе HTML или загрузи проект на GitHub Pages.
Для запуска нужен интернет: Three.js подключается с CDN.
Телефон: левый джойстик, БЕГ, ПРЫЖОК, ДЕЙСТВИЕ.
ПК: WASD/стрелки, Shift — бег, мышь — поворот камеры.
Это новая стартовая версия-прототип: трёхмерный город, персонаж, машины, камера и задание с наградой.
Это не готовый APK. Для APK понадобится Android-оболочка/WebView и сборка проекта.
